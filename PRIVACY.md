# PopTranslate — Privacy Policy

PopTranslate does not collect, store, or share any personal data.

When you select text on a webpage, that text is sent directly to the Google Translate API (translate-pa.googleapis.com) solely to retrieve a translation. If that request fails, the text is sent to the MyMemory translation API (mymemory.translated.net) instead. These are direct browser-to-API requests. PopTranslate itself does not see, store, log, or transmit your selected text to any server controlled by the developer.

Your preferences (source and target language, whether the popup is turned on, and the names of any sites where you turned it off) are saved locally using chrome.storage.sync, which syncs across your own Chrome profile only. This data never leaves your Google account.

No analytics, no tracking, no advertising, no third-party data sharing.
